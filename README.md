# FIREBITE — Smash Burger Website

A bold, cinematic and fully responsive landing page for a fictional smash burger restaurant.

## Features

- Responsive desktop and mobile layout
- Animated sections and scrolling ticker
- Interactive food menu
- Working shopping bag with total calculation
- Mobile navigation
- Optimized WebP food imagery
